# Mini CRM System

A responsive **Mini CRM (Customer Relationship Management) System** built using **HTML, CSS, and JavaScript**. This application helps users manage customer leads by adding, viewing, and organizing customer information through a simple and intuitive interface.

## 🚀 Features
- Add new customer leads
- Store customer details such as Name, Email, Phone Number, and Status
- View all leads in a clean and organized layout
- Responsive and user-friendly interface
- Simple and lightweight design
- Easy to customize and extend

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure
```
MiniCRM/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🎯 Project Objective
The goal of this project is to demonstrate the fundamentals of front-end web development by building a simple CRM application. It focuses on form handling, DOM manipulation, responsive UI design, and basic data management using JavaScript.
